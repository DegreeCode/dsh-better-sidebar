## Resolution and retained fork behavior

The only merge conflicts were version strings in `package.json`, `dsh.plugin.json`, and `src/client/service.ts`; all three use 0.28.2. The DSH peer baseline remains `^0.2.1-rc.1`.

One upstream trailing blank line at the end of `tests/e2e/mount.e2e.ts` was removed so the merged diff passes `git diff --check`; it changes no test behavior.

Preserved fork changes:

- Korean dictionary corrections, `locale/ko.json`, packaged `README_KO.md`, and Korean navigation links.
- Following DSH's own third-language locale, lazy dictionaries, and updates when those dictionaries arrive.
- GitHub release tarballs built on tag push, without publishing to upstream's npm package.
- Dead-code removal, shared reduced-motion helper, and removal of the unused direct `rxjs` dependency.

The fork-only paths were compared byte-for-byte against the starting commit (including deleted files); `README_KO.md` is the intentional exception because it now documents upstream's new behavior and compatibility. The fork's added/removed lines in all five shared client files (`Sidebar.tsx`, `TasksGraph.tsx`, `TextEditor.tsx`, `locales-ko.ts`, and `locales.ts`) were also compared exactly against their original changes.

The Korean README retains the existing v0.28.1 fork tarball URL and distinguishes it from the newly integrated source and upstream's npm package. No uncreated v0.28.2 fork release is advertised.

## Behavior to retain from upstream

- Cold cwd resolution reads a stored session header instead of decoding the entire log, sharing in-flight reads. Before attachment, a session uses its original workspace; after attachment, the next 5-second poll follows the committed cwd/worktree again.
- Background-session file reconciliation and a consistent session address base prevent stale-path saves and wrong-checkout opens.
- Editor reload/save-baseline and reference-chip fixes, side-chat rendering and archive fixes, Git output bounds and graph tags, and visibility/rendering optimizations are included unchanged.
